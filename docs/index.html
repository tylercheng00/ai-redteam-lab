AI Red-Teaming Lab

AI 紅隊測試實驗室：滲透及越獄研究

How easily can an LLM application be talked out of its own rules? This lab studies prompt injection and jailbreak techniques and the defences against them — and measures robustness safely, by trying to extract a meaningless canary code word instead of anything harmful.

大型語言模型應用有多容易被「說服」違反自身規則？本實驗室研究提示注入及越獄技術與相應防禦，並以安全方式量度穩健性：測試目標只是一個無意義的金絲雀（canary）暗號，而非任何有害內容。

Scope & responsible use 研究範圍及負責任使用

          
    
            
  • Canary-only. Every attack targets a harmless code word; no harmful content is requested or produced.只以無害暗號作測試目標，不要求亦不產生任何有害內容。
    •

01 · Threat model · 威脅模型

      
Where instructions can sneak in 指令可以從哪裏混入

      
An LLM application mixes trusted instructions (the system prompt) with untrusted text (user messages, documents, web pages). Prompt injection exploits the fact that the model sees all of it as one stream of tokens. Defences sit at the input, inside the prompt and at the output.
LLM 應用把可信指令（系統提示）與不可信文字（用戶訊息、文件、網頁）混在一起。提示注入正是利用模型把一切視為同一串字元的弱點。防禦可放在輸入端、提示之內及輸出端。

04 · Results · 結果

      
Robustness matrix 穩健性矩陣

      
ASR = attack success rate (share of techniques that leaked the canary). FPR = false-positive rate (share of benign prompts wrongly blocked or refused). No single defence covers everything; layering does — on this simulated target.
ASR＝攻擊成功率；FPR＝誤判率（正常請求被錯誤攔截的比例）。沒有單一防禦能覆蓋所有技術，多層防禦才可以——以上結果只適用於此模擬目標。

quickstart.py


import redteam_lab as rl

# robustness matrix: attacks × defence configurations
print(rl.to_markdown(rl.evaluate()))

# compose defences around any target
target = rl.DefendedTarget(
    rl.ToyAssistant(), rl.DEFAULT_CANARY,
    detector=rl.InjectionDetector(threshold=0.5),
    use_spotlight=True, output_filter=True,
)
trial = rl.run_trial(target, rl.attacks.get("indirect"))
print(trial.leaked, target.last_events)

defenses.py — spotlighting


def spotlight(user, marker="^"):
    """Datamarking: interleave a marker through
    untrusted blocks so they read as data."""
    return _DATA_BLOCK.sub(
        lambda m: "<<DATA>>"
          + marker.join(m.group(1).split())
          + "<</DATA>>",
        user)
